# Ember & Bean Café Website

## Goal
Create a polished single-page café website that closely follows the attached reference: warm editorial luxury, cinematic photography, refined typography, asymmetric layouts, and a cohesive real-world hospitality feel.

## Build
- Establish the full visual system: espresso, ivory, olive, beige, brown, and copper tones; elegant serif display type; clean sans-serif interface type; restrained borders, shadows, radii, and motion.
- Build the announcement bar, sticky navigation, cinematic hero, story, signature menu, experience, gallery, value pillars, testimonials, visit section, WhatsApp callout, social grid, newsletter, and premium footer.
- Create a custom botanical/bean brand mark and use a cohesive set of generated café photographs matching the reference’s warm natural lighting and organic-modern interiors.
- Add a full menu overlay with category switching and realistic menu entries.
- Add an accessible fullscreen gallery with previous/next controls, close control, click navigation, and keyboard support.
- Add a reservation overlay with validation and an honest demo-only success state.
- Make every action functional: smooth section navigation, active navigation state, mobile menu, WhatsApp links, directions link, Instagram link, newsletter validation, and back-to-top.

## Responsive treatment
- Compose distinct mobile layouts rather than shrinking the desktop design.
- Test at representative phone, tablet, and desktop widths for overflow, cropping, navigation, typography, modal usability, and touch targets.
- Keep below-the-fold imagery lazy-loaded and animations subtle with reduced-motion support.

## Quality and verification
- Add page-specific search and social metadata, semantic structure, descriptive image text, and a custom favicon treatment.
- Validate the complete flow in the live preview on desktop and mobile, including menu, gallery, reservation, navigation, newsletter, external actions, and keyboard controls.
