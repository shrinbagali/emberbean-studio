# Ember & Bean Showcase

Build a complete, polished, production-quality café website based on the attached reference image.

IMPORTANT:

* The attached image is the PRIMARY visual reference.
* Recreate its overall visual hierarchy, composition, spacing, typography feel, color palette, imagery style, section arrangement, cards, navigation, buttons, and premium atmosphere as closely as possible.
* Do NOT make a generic restaurant template.
* Do NOT simplify the design into a basic landing page.
* The final result must look like a website created by a professional design studio for a premium real-world café.
* It must feel commercially hireable and impressive enough for me to show to potential café owners as my first client demo.
* The reference image should guide the visual direction, while the generated website must be fully functional and responsive.

Tagline:
